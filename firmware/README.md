# 人体模倣前腕ロボットの制御システム

DynamixelサーボモーターとTeensy 4.1マイクロコントローラーを使用した22アクチュエーター人体模倣前腕ロボットの包括的制御システム。

## 概要

このプロジェクトは、人間の手と前腕の筋肉構造を模倣した前腕ロボットの高度な制御システムを実装しています。システムは22個の個別のDynamixelサーボモーターを制御し、それぞれが異なる筋肉を表現し、位置制御、電流制御、ハイブリッド電流ベース位置制御など、さまざまな動作モードをサポートしています。

## 必要なハードウェア

### マイクロコントローラー
- **Teensy 4.1**（SDIOと十分なI/Oのために必要）

### サーボモーター
- **22個のDynamixelサーボモーター**（プロトコル2.0対応）
- Dynamixel通信インターフェース（Serial2、ピン7-8）
- 方向制御ピン（ピン2）

### ストレージ
- **SDカード**（Teensy 4.1内蔵SDIOを使用）

### 追加コンポーネント
- 力量計センサー（アナログピンA16）
- 外部同期信号入力（ピンA17）
- PWMサーボ出力（ピン9）補助アクチュエーター用
- シリアルディスプレイとデバッグインターフェース

## ソフトウェア依存関係

### PlatformIOライブラリ
- `robotis-git/Dynamixel2Arduino@^0.6.3`
- `TeensyThreads`（マルチスレッド用）
- `SdFat`（SDカード操作）
- `Servo`（PWMサーボ制御）

## 筋肉マッピング

システムは以下の筋肉を表現する22個のサーボモーターを制御します：

### 指筋肉（0-14）
- **IndexFDP**（0）：示指深指屈筋
- **MiddleFDP**（1）：中指深指屈筋
- **MiddleFDS**（2）：中指浅指屈筋
- **RingFDP**（3）：薬指深指屈筋
- **PinkyFDP**（4）：小指深指屈筋
- **FPL**（5）：長母指屈筋
- **APM**（6）：母指内転筋（無限巻取り機構）
- **OPM**（7）：母指対立筋
- **APB**（8）：短母指外転筋
- **EIP**（9）：示指伸筋
- **EDM**（10）：小指伸筋
- **ED**（11）：総指伸筋
- **EPB**（12）：短母指伸筋
- **EPL**（13）：長母指伸筋
- **APL**（14）：長母指外転筋

### 手首筋肉（15-21）
- **FCR**（15）：橈側手根屈筋
- **FCU**（16）：尺側手根屈筋
- **ECRL**（17）：長橈側手根伸筋
- **ECU**（18）：尺側手根伸筋
- **SPN**（19）：回外筋（無限巻取り機構）
- **BPB**（20）：上腕二頭筋
- **PT**（21）：円回内筋

## 制御モード

### 1. 電流ベース位置制御（デフォルト）
- 位置制御と電流制御を組み合わせ
- 位置目標を持つコンプライアントモーションを可能にする

### 2. 純粋電流制御
- 直接電流・トルク制御
- 共収縮と剛性制御に使用

### 3. 位置制御
- 従来の位置のみ制御
- 精密な位置決めに使用

## 使用方法

### 初期設定

1. **ファームウェアの書き込み：**
   ```bash
   pio run --target upload
   ```

2. **シリアルモニターに接続：**
   ```bash
   pio device monitor
   ```

3. **システムの初期化：**
   - システムは自動的にDynamixel通信を初期化
   - モーション保存用のSDカードが初期化される

### 利用可能なコマンド

#### 教示モード
```
Teach
```
- 新しいモーションを記録する教示モードに入る
- 手を手動で位置決めし、ウェイポイントを保存
- 無限巻取り機構の使用をサポート（y/nプロンプト）

#### モーション再生
```
Start
```
- SDカードから記録されたモーションを再生
- 反復回数を選択
- モーションタイプを選択（1: リラックス、2: 把握）

#### システム制御
```
Relax    # 全モーターのトルクを無効化
Fix      # 低電流保持を有効化
Show     # 現在のサーボ位置を表示
```

#### ファイル管理
```
ls       # SDカード上のファイル一覧表示
Delete   # 保存されたモーションファイルを削除
```

#### テストと校正
```
Static   # 関節剛性テスト（4モード）
Random   # ランダム筋肉活動テスト
Unit     # 個別筋肉ユニットテスト
FingerDrive  # 個別指駆動テスト
```

#### マニュアル制御
```
Manual   # マニュアル位置入力（22個のカンマ区切り値）
servo    # 補助PWMサーボテスト（0-100%）
```

### モーションタイプ

#### 把握モーション
- 協調制御により指屈筋を活性化
- 安定した把握のための共収縮を実装
- 筋肉群に基づく電流制限の調整

#### リラックスモーション
- 筋肉の緊張を適切に軽減
- 最小限の保持電流を維持
- エネルギー効率を優先

## 設定

### 電流制限（mA単位）
- **指屈筋：** 筋肉により20-100mA
- **指伸筋：** 筋肉により20-400mA
- **手首筋肉：** 300mA
- **前腕筋肉：** 60-200mA

### 位置制限
- `muscle_specs.h`のテーブルで筋肉ごとに前進・後進限界を定義
- 安全制限により機械的損傷を防止

### タイミングパラメータ
- **サンプリング周期：** 10ms（100Hz）
- **デフォルトモーション時間：** 5秒
- **通信タイムアウト：** 10ms

## 安全機能

- **位置制限：** ハードウェア制限により過伸展を防止
- **電流制限：** モーター損傷と過熱を防止
- **タイムアウト保護：** 通信障害検出
- **トルク無効化：** 緊急停止機能

## データログ

システムはCSV形式でモーションデータをログ記録：
- タイムスタンプ
- 全22モーターの電流読取り値
- 全22モーターの位置読取り値
- オプションの力量計データ

## トラブルシューティング

### よくある問題

1. **Dynamixel通信障害：**
   - 配線とボーレート（1Mbps）を確認
   - サーボIDが連続的に0-21であることを確認
   - プロトコルバージョン（2.0）を確認

2. **SDカードエラー：**
   - SDカードが適切にフォーマットされていることを確認（FAT32）
   - Teensy 4.1のSDIO接続を確認

3. **モーションが不安定またはがたつく：**
   - 筋肉初期化の電流制限を調整
   - 干渉の位置制限を確認
   - 機械的組み立てを確認

### デバッグ出力
システムは`DEBUG_SERIAL`（SerialUSB）を通じて包括的なシリアルデバッグを提供。トラブルシューティングのため詳細出力を有効化してください。
