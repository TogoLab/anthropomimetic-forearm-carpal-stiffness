# 剛性の「方向（異方性の向き）」が条件間で異なるかの統計検定

Finger Muscle 条件と Wrist+Finger Muscles（Combined）条件で、剛性の**大きさ**ではなく
**方向（角度依存パターン／異方性楕円の向き）**が異なることを示すために行った 3 つの統計検定の
詳細をまとめる。

- 検定1: カテゴリ二元配置分散分析の交互作用（omnibus）
- 検定2: 調和（円周）モデルの入れ子 F 検定（1次／2次成分の分解）
- 検定3: 剛性楕円フィット＋最大剛性角の回転に対する並べ替え検定（**主結果候補**）

対応スクリプト:
- `direction_anova_finger_vs_combined.py` … 検定1
- `direction_harmonic_finger_vs_combined.py` … 検定2
- `direction_ellipse_rotation_repo.py` … 検定3

---

## 0. 共通のデータ基盤

- **観測単位**: 1 試行 = 1 つの剛性値 `stiffness`（`lib.analyze.calcurate_sttiffness` で算出）。
- **設計**: 2 条件 × 12 角度（0,30,…,330°）× 8 反復。有効試行のみ採用。
- **キャッシュ**: `results/direction_anova_long_data.csv`（列 `stiffness, condition, angle, rep`）。
  重い剛性再計算を避けるため検定2・3はこれを読み込む。
- **前処理（検定2・3）**: `stiffness < 5 N/mm` の生理的に非現実な外れ値（中央値≈82 に対し 0.40,
  0.46 の 2 件）を除外。除外有無で結論は不変であることを確認済み。
- 有効 n: 各条件 95 試行（フィルタ後）。

記号:
- $y$ : 剛性（または変換後の値）
- $\theta$ : 押下角度 [rad]、$\theta = \text{angle}\times\pi/180$
- 条件 $i\in\{\text{Finger},\text{Combined}\}$、角度 $j\in\{1,\dots,12\}$、反復 $k$

## 検定1: 二元配置分散分析の condition × angle 交互作用

**スクリプト**: `direction_anova_finger_vs_combined.py`

### 仮説
角度ごとの剛性プロファイル（角度依存パターン）が条件間で異なる
＝ 条件と角度の**交互作用**が存在する。

### モデル
角度を 12 水準の**カテゴリ変数**として二元配置 ANOVA を組む:

$$
y_{ijk} = \mu + \alpha_i + \beta_j + (\alpha\beta)_{ij} + \varepsilon_{ijk}
$$

- $\alpha_i$ : 条件主効果、$\beta_j$ : 角度主効果、$(\alpha\beta)_{ij}$ : **交互作用**（これが検定対象）。
- 大きさの差を除くため、各条件を自条件のグランド平均で割った正規化値
  $y^{\text{norm}}_{ijk} = y_{ijk}/\bar y_{i\cdot\cdot}$ を応答とした版も実施（条件主効果は構成上ほぼ消える）。

### 統計量
交互作用項の **F 値**:

$$
F = \frac{\text{MS}_{\text{interaction}}}{\text{MS}_{\text{error}}}
  = \frac{\text{SS}_{\text{interaction}} / \text{df}_{\text{interaction}}}{\text{SS}_{\text{error}} / \text{df}_{\text{error}}}
$$

- 分子（シグナル）: 加法モデルからの非加法ズレの二乗和。セルごとの交互作用成分
  $\widehat{(\alpha\beta)}_{ij} = \bar y_{ij\cdot} - \bar y_{i\cdot\cdot} - \bar y_{\cdot j\cdot} + \bar y_{\cdot\cdot\cdot}$
  を二乗して反復数で重み付けて合計したもの。
- 分母（ノイズ）: セル内の反復ばらつき（誤差分散）。
- $\text{df}_{\text{interaction}} = (2-1)(12-1) = 11$。

### 算出手順
1. ロングデータを構築（`build_long_data`）。
2. 正規化値を計算（`normalize`）。
3. `statsmodels` の式 `y ~ C(condition) * C(angle)` で OLS フィット。
4. `anova_lm(model, typ=2)` で **Type II 平方和**の ANOVA 表を取得。
   - Type II は交互作用項に関しては Type III と一致するため、交互作用の検定には妥当。
   - ただし主効果は交互作用がある状況では解釈しない（本検定では交互作用のみ報告）。
5. 交互作用行 `C(condition):C(angle)` の F と p を読む。
6. 同じ手順を生値 `stiffness` と正規化値 `stiffness_norm` の両方で実施。

### 結果
- 正規化版: **F(11, …) = 4.68, p = 3.2×10⁻⁶**（有意）
- log 変換版（頑健性確認）: F = 3.27, p = 4.5×10⁻⁴（有意）

### 解釈と限界
- 「角度プロファイルが**何らかの形で**異なる」ことを示す **omnibus 検定**。
- 1 つの角度での突出（大きさのブレ）でも有意になり得て、「異方性の向きが回転した」ことを
  特定はしない。→ そこを切り分けるのが検定2・3。
- 正規化（グランド平均除算）は大きさ除去のアドホックな方法。原理的には log 変換（乗法的な
  大きさ差を加法的な主効果に変換）が等価で望ましい。両方で有意なので結論は頑健。

## 検定2: 調和（円周）モデルの入れ子 F 検定

**スクリプト**: `direction_harmonic_finger_vs_combined.py`

### 動機
角度は円周変数（0–330°）なので、カテゴリ 11 自由度ではなく**調和項**で表すと
自由度が節約でき、かつ成分の物理的意味（非対称性 vs 異方性軸）が分離できる。

### モデル
$\log$ 剛性を条件 × 調和項で表す:

$$
\log K = \beta_0 + \alpha\,\mathbb{1}[\text{cond}] + \sum_{m=1}^{2}\bigl(b_{mc}\cos m\theta + b_{ms}\sin m\theta\bigr) + (\text{condition} \times \text{harmonics の交互作用})
$$

- **log スケール**: 条件間の乗法的な大きさ差を加法的な条件主効果 $\alpha$ に押し込めるので、
  **condition × 調和項の交互作用が「大きさに依存しない形（shape）」を表す**。
  → 検定1の正規化のようなアドホックな割り算が不要。
- 1次調和（$\cos\theta,\sin\theta$、360°周期）= 方向**非対称性**（片側だけ硬い）。
- 2次調和（$\cos 2\theta,\sin 2\theta$、180°周期）= 双方向の**異方性軸**（楕円の主軸に対応）。

### 統計量
追加した交互作用項に対する**入れ子モデルの F 検定**（部分 F 検定）:

$$
F = \frac{(\text{SSR}_{\text{reduced}} - \text{SSR}_{\text{full}}) / q}{\text{SSR}_{\text{full}} / (n - p_{\text{full}})}
$$

- $\text{SSR}$ : 残差平方和。reduced = 交互作用なし（加法）モデル、full = 交互作用ありモデル。
- $q$ : 追加した交互作用項の数（= 検定する自由度）。
- 直観: 「交互作用を入れたことで残差がどれだけ減ったか」をノイズで規格化したもの。

### 算出手順
1. キャッシュ読み込み → フィルタ → `theta`, `logK` と調和列 `h1c,h1s,h2c,h2s` を作成。
2. 3 種類の交互作用を入れ子比較（`anova_lm(reduced, full)`）:
   - **結合**: full に `condition:(h1c,h1s,h2c,h2s)`（$q=4$）
   - **1次**: full に `condition:(h1c,h1s)`（$q=2$）
   - **2次**: full に `condition:(h2c,h2s)`（$q=2$）
   - reduced は常に加法モデル `logK ~ C(condition) + h1c+h1s+h2c+h2s`。
3. 各条件を個別に $\log K \sim$ 調和でフィットし、幾何量を抽出:
   - 1次振幅 $A_1=\sqrt{b_{1c}^2+b_{1s}^2}$、ピーク方向 $\phi_1=\operatorname{atan2}(b_{1s},b_{1c})$
   - 2次軸 $\theta_{\text{axis}} = \tfrac12\operatorname{atan2}(b_{2s},b_{2c})\ (\bmod 180°)$

### 結果
| 交互作用 | 自由度 $q$ | F | p | 意味 |
|---|---|---|---|---|
| 結合（全調和） | 4 | 10.28 | 1.6×10⁻⁷ | 角度パターンが条件間で異なる |
| 1次調和 | 2 | 14.90 | 1.0×10⁻⁶ | **方向非対称性**が異なる |
| 2次調和（異方性軸） | 2 | 4.08 | 0.018 | **異方性軸の向き**が異なる |

幾何量（log フィット）: Finger 1次ピーク 293° / 2次軸 68°、Combined 1次ピーク 354° / 2次軸 104°。

### 解釈と限界
- 違いの主因は 1次成分（方向非対称性、p=10⁻⁶）で、2次成分（軸の回転、p=0.018）も有意。
- 2次成分だけでは「楕円の向き」だが、1次が大きいためプロファイルは純粋な楕円ではない。
  → 楕円の枠組みで明示的に扱うのが検定3。

## 検定3: 剛性楕円フィット＋最大剛性角の回転（並べ替え検定）

**スクリプト**: `direction_ellipse_rotation_repo.py`
**フィット法は論文・リポジトリと同一**（`lib.fitting.fit_cartesian`）。

### 仮説
剛性楕円の主軸（最大剛性方向）が条件間で**回転**している。大きさとは独立。

### 楕円フィット（論文の手法）
1. 各条件で角度ごとの**平均剛性** $\bar K_j$ を求める。
2. 極→直交変換 $x_j=\bar K_j\cos\theta_j,\ y_j=\bar K_j\sin\theta_j$。
3. `fit_cartesian(x,y)`: 点群から楕円までの**幾何距離の二乗和**を `L-BFGS-B` で最小化し、
   楕円パラメータ $(a,b,h,k,\phi)$ を得る（中心 $(h,k)$ はデータ重心に固定）。

   $$\min_{a,b,\phi}\ \sum_j\left[\left(\frac{x'_j}{a}\right)^2+\left(\frac{y'_j}{b}\right)^2-1\right]^2,\quad (x',y')=R(\phi)\,(x-h,\,y-k)$$
4. 楕円上を密にサンプルし、**原点からの距離** $\lVert(x_e,y_e)\rVert$ が最小／最大となる点の
   角度を求める:

   $$\theta_{\max} = \operatorname{atan2}(y_e^{\max}, x_e^{\max}),\qquad \theta_{\min} = \operatorname{atan2}(y_e^{\min}, x_e^{\min})$$

   これが論文で報告している**最小剛性角・最大剛性角**（`phis_min`/`phis_max`）。

### 統計量
2 条件の**最大剛性角の円周差**（楕円の硬い方向の回転量）:

$$
\Delta_{\max} = \text{circdiff}(\theta_{\max}^{\text{Finger}},\, \theta_{\max}^{\text{Combined}}),
\qquad \text{circdiff}(a,b)=\min\bigl(|a-b|\bmod 360,\ 360-|a-b|\bmod 360\bigr)\in[0,180]
$$

- **統計量が「角度」そのもの**なので、全体の大きさ（スケール）に不変。
  → 「大きさではなく向き」を定義上クリーンに検定できる。

### 検定1: 層別並べ替え検定（p 値）
帰無仮説「向きは条件に依らない」のもとでの $\Delta_{\max}$ の分布を、ラベル入れ替えで構成:

1. **各角度内で**条件ラベルをシャッフル（角度構造を保つ層別並べ替え）。
2. 擬似 Finger / 擬似 Combined それぞれで平均→楕円フィット→$\theta_{\max}$→$\Delta_{\max}^{(\text{perm})}$ を再計算。
3. 1–2 を $N=5000$ 回繰り返し、帰無分布を得る。
4. p 値 $= \dfrac{\#\{\Delta^{(\text{perm})} \ge \Delta^{\text{obs}}\}+1}{N+1}$。

### 検定2: ブートストラップ（信頼区間）
1. 各 (condition, angle) セル内で反復を**復元抽出**。
2. 平均→楕円フィット→$\theta_{\max}$→$\Delta_{\max}$ を再計算。
3. $N=3000$ 回繰り返し、$\Delta_{\max}$ の 2.5/97.5 パーセンタイルを 95% CI とする。

### 結果
| | 最大剛性角 | 最小剛性角 |
|---|---|---|
| Finger | 254.0° | 151.7° |
| Combined | 302.2° | 197.9° |

- 回転 **$\Delta_{\max}$ = 48.2°**（$\Delta_{\min}$ = 46.3° と整合）
- 並べ替え検定 **p = 0.0038**（帰無中央値 16.6°、95 パーセンタイル 37.5° に対し観測 48°）
- ブートストラップ 95% CI = [23.8°, 176.3°]

### 解釈と限界
- 最大剛性方向が約 48° 回転しており、並べ替え検定で **p = 0.0038** と強く有意。
- **ブートストラップ CI の上限が 176° と暴れる**: 原点オフセットのある楕円で、リサンプル時に
  楕円がほぼ円に近づくと $\theta_{\max}$ が ±180° 反転するため。角度差の対称 CI が不安定になるので、
  **p 値を主たる推定**とし、CI はブートストラップ分布が重裾である旨を添える。下限 24° が 0 から
  十分離れている点は強調できる。
- `fit_cartesian` 内の divide-by-zero 警告は退化楕円（$b\approx0$）が稀に出るためで結果に影響なし。

# 付録A: 並べ替え検定（permutation test）の詳細

検定3の主たる推定に用いた並べ替え検定について、考え方・手順・前提・図を詳述する。

## A.1 一言で言うと

> **「条件ラベルをデタラメに貼り替えても、観測したのと同じくらい大きな回転が出るか？」を、
> 実際に何千回も試して確かめる検定。**

もし「Finger と Combined で楕円の向きは本当は変わらない」のなら、どの試行がどちらの条件かという
**ラベルには意味がない**はず。ならばラベルをランダムに入れ替えても、回転角はたまたま似た値に
なるはずである。実際に入れ替えを繰り返して「ラベルが無意味なときの回転角の分布（＝帰無分布）」を
作り、観測した 48° がその中でどれだけ珍しいかを数える。

## A.2 なぜこの検定を選んだか

- **統計量が「角度（回転量）」**で、その理論的な標本分布が分からない。t/F のような既成の分布を
  当てはめられないため、データ自身を並べ替えて分布を自前で構成する必要がある。
- **分布の正規性などの仮定を置かない**（ノンパラメトリック）。少数 n（各条件 95 試行、角度あたり
  7–8 反復）でも、仮定違反の心配なく p 値が得られる。
- 統計量が角度なので**全体の大きさ（スケール）に不変** → 「大きさではなく向き」を狙い撃ちできる。

## A.3 帰無仮説と交換可能性（exchangeability）

- **帰無仮説 $H_0$**: 剛性の角度プロファイル（ひいては楕円の向き）は条件ラベルに依存しない。
- $H_0$ のもとでは、**同じ角度で測った試行どうしは条件ラベルを入れ替えても確率的に等価**
  （exchangeable）。この交換可能性が並べ替えの妥当性の根拠。
- **層別（stratified）にする理由**: 角度そのものは強い効果を持つ（剛性は角度依存）。ラベルを全体で
  無差別にシャッフルすると、たまたま片方の擬似条件に特定の角度が偏り、角度効果が条件差に
  漏れ込む。これを防ぐため、**各角度の内側だけでラベルを入れ替える**。こうすると擬似 Finger /
  擬似 Combined は常に 12 角度を同数ずつ含み、検定するのは「同一角度集合のもとでの**割り当ての
  違い**」だけになる。

## A.4 統計量

2 条件の最大剛性角の円周差（楕円の硬い方向の回転量）:

$$
\Delta_{\max} = \text{circdiff}\bigl(\theta_{\max}^{\text{Finger}},\ \theta_{\max}^{\text{Combined}}\bigr)\in[0,180]
$$

$\theta_{\max}$ は A.5 の通り、各擬似条件で「角度平均 → `fit_cartesian` 楕円フィット →
原点から最遠点の角度」として再計算する。**1 回の並べ替えごとに楕円フィットを 2 回**行う点に注意
（軽くない計算。検定3全体で約 6 分）。

## A.5 アルゴリズム（擬似コード）

```
入力: 各試行の (stiffness, condition, angle)   # フィルタ後 190 試行
観測値の計算:
    θmax_F = ellipse_max_angle( mean_per_angle(Finger 試行) )
    θmax_C = ellipse_max_angle( mean_per_angle(Combined 試行) )
    Δ_obs  = circdiff(θmax_F, θmax_C)            # = 48.2°

帰無分布の構成:  for i in 1..N (=5000):
    perm = condition ラベルのコピー
    for each 角度 a in {0,30,...,330}:
        perm[a の試行] = shuffle(condition[a の試行])   # 層別シャッフル
    θF = ellipse_max_angle( mean_per_angle(perm=="Finger" の試行) )
    θC = ellipse_max_angle( mean_per_angle(perm=="Combined" の試行) )
    null[i] = circdiff(θF, θC)

p 値:
    p = ( #{ null[i] >= Δ_obs } + 1 ) / ( N + 1 )
```

- `ellipse_max_angle` = 角度平均 → `fit_cartesian` → 原点から最遠点の `atan2`（検定3本文 A 参照）。
- 乱数シードは `SEED=20250620` で固定（再現可能）。

## A.6 p 値の式と「+1」の理由

$$
p = \frac{\#\{\Delta^{(\text{perm})} \ge \Delta^{\text{obs}}\} + 1}{N + 1}
$$

- 分子・分母の **+1** は「観測した割り当てそのものも 1 つの並べ替え」として常に数える処理。
  これにより $p$ が厳密に 0 にならず（$N=5000$ でも下限 $1/5001\approx0.0002$）、モンテカルロ
  並べ替えで $p$ 値が不当に小さく出るのを防ぐ（Phipson & Smyth, 2010）。
- 片側検定（回転は向きを問わない大きさ $[0,180]$ なので、$\Delta$ が**大きい**ほど極端）。

## A.7 結果と帰無分布図（図B）

- 観測 $\Delta_{\max} = 48.2°$。
- 帰無分布: 中央値 16.6°、95 パーセンタイル 37.5°。観測 48° は分布のほぼ完全に外側。
- $\#\{\text{null} \ge 48.2°\} = 18$ 程度 / 5000 → **p = 0.0038**。

- 灰色ヒストグラム: 5000 回のラベルシャッフルで得た回転角の帰無分布。

- 緑の裾＋ズーム挿入図: 観測値以上の領域（p 値に相当する確率質量）。

並べ替え検定を採るときの**定番の図**であり、「観測値が帰無分布の裾にある」ことを視覚的に示す。
本文には楕円図（`direction_ellipse_rotation_repo.png`）に回転角と p を注記し、この図Bは
Supplementary に置く構成が一般的。

## A.8 並べ替え検定 vs ブートストラップ（役割の違い）

| | 並べ替え検定 | ブートストラップ |
|---|---|---|
| 操作 | 条件ラベルを**入れ替え**（$H_0$ を模す） | セル内反復を**復元抽出**（標本変動を模す） |
| 答える問い | 「向きの差は偶然か？」→ **p 値** | 「回転量はどれくらい不確か？」→ **信頼区間** |
| 本検定での扱い | **主たる推定**（p=0.0038） | 補助（95% CI [24°, 176°]、ただし上限が暴れる※） |

※ 原点オフセットのある楕円では、リサンプル時に楕円がほぼ円に近づくと $\theta_{\max}$ が ±180°
反転し得るため、角度差の対称 CI が不安定になる。p 値（並べ替え）を主とし、CI は分布が重裾で
ある旨を添えるのが誠実。
